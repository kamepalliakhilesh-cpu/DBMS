Relational Schema & ER Architecture

Exact Relational Database Specification (3NF Normalized, 6 Entities, Referential Integrity).
Test SQL Queries
Entity Relationship Cardinalities
Disaster → Victim (1 : N)
One disaster event affects one or more victims.
ReliefCenter → Resource (1 : N)
One relief centre stores and manages multiple resource items.
ReliefCenter → Volunteer (1 : N)
One relief centre coordinates multiple deployed volunteers.
Victim → Distribution (1 : N)
One registered victim can receive multiple resource deliveries.
Resource → Distribution (1 : N)
One resource item appears in multiple distribution transactions.

Disaster

Entity 1
PK Disaster_ID INT
Type VARCHAR(50)
Location VARCHAR(100)
Date DATE
Severity_Level VARCHAR(20)

Victim

Entity 2
PK Victim_ID INT
Name VARCHAR(100)
Age INT
Contact VARCHAR(15)
Address VARCHAR(200)
FK Disaster_ID INT → Disaster

Entity 3

Capacity INT

Resource

Entity 4

FK Center_ID INT → ReliefCenter

Entity 6
